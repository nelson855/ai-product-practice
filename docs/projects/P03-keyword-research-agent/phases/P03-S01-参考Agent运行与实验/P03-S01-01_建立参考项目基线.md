# P03-S01-01：建立参考项目基线

## 1. 核心结论

固定主参考和产品化补充参考的版本、License、环境、归档状态与可运行条件，并明确两者分别用于学习什么。本需求不修改业务逻辑。

## 2. 状态

| 属性 | 内容 |
|---|---|
| 状态 | 未开始 |
| 必需前置 | 无 |
| 主要交付物 | `progress/p03/reference_baseline.md` |

## 3. 实现范围

- 将主参考放入 `references/p03-langchain-rag-research-agent-template/`；
- 将产品化补充参考放入 `references/p03-deep-research-agent-product-reference/`；
- 分别记录 URL、分支、commit SHA、License、归档状态和初始 Git 状态；
- 阅读 README、依赖、环境变量、测试和部署配置；
- 定位主参考中的 Graph、State、Routing、Plan、Retrieval 和 Subgraph；
- 定位补充参考中的 Search Provider、迭代研究、错误恢复、Web UI 和限制；
- 记录运行环境、外部账户、模型、搜索和已知陈旧依赖；
- 给每项初始结论标记 E1～E4 证据等级。

## 4. 边界

- 不修改参考仓库；
- 不为了追求完整启动而立即升级框架和全部依赖；
- 不记录真实 Secret；
- 不假设两个项目具有相同 Agent 定义；
- 不开始 Java 方案设计。

## 5. 验收标准

- 两个仓库的角色和边界明确；
- 主参考核心目录和补充参考产品化入口已经定位；
- 可运行、可能需要修复和仅能静态分析的部分明确；
- 环境变量与外部服务按敏感性和费用分类；
- 参考仓库保持无业务改动。

## 6. Coding Agent 执行要求

只完成基线记录和安全可行性检查。报告证据等级、阻塞和两个仓库的 Git 状态后停止。
