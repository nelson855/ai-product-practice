# P03-S01：参考 Agent 运行与实验

## 1. 目标

从两个参考项目中获得 Graph、Routing、Plan、Retrieval、State、Loop 和产品化行为的真实证据。主参考仓库已归档时，允许以局部运行、测试和源码实验替代无法形成的完整运行，但必须明确证据等级。

## 2. 子需求

| 子需求 | 目标 | 前置 |
|---|---|---|
| P03-S01-01 | 建立两个参考项目的版本和环境基线 | 无 |
| P03-S01-02 | 验证核心 Graph 和研究流程 | P03-S01-01 |
| P03-S01-03 | 实验 Routing、Loop 和 State | P03-S01-02 或明确运行阻塞 |

## 3. 证据等级

| 等级 | 含义 |
|---|---|
| E1 | 实际端到端运行观察 |
| E2 | 局部节点、测试或最小脚本运行观察 |
| E3 | 源码和配置静态分析 |
| E4 | README 或文档声明，尚未验证 |

结论必须标明主要证据等级，不能把 E4 写成 E1。

## 4. 阶段边界

- 允许修改参考仓库做注释和小实验；
- 不为修复归档项目而进行大规模升级；
- 不开始 Java Agent 正式实现；
- 不把 LangGraph 抽象直接翻译为 Java 类；
- 不输出或要求模型隐藏思维链；
- 不购买服务或部署，除非用户明确同意。

## 5. 建议交付物

```text
progress/p03/reference_baseline.md
progress/p03/upstream_agent_report.md

```

## 6. 阶段完成定义

- 两个参考仓库的用途、版本和可运行性已记录；
- 核心 Graph/流程至少形成 E2 或更高证据，无法达到时说明原因；
- Routing、Loop、State 至少两项有受控实验；
- 已形成 Tool、State、停止、Tracing 和产品化问题清单；
- 实验差异、测试和 Git 状态已报告。
