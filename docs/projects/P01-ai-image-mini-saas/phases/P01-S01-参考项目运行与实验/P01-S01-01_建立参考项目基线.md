# P01-S01-01：建立参考项目基线

## 1. 核心结论

将 Backblaze AI SaaS Starter Kit 放入固定参考目录，记录不可歧义的版本、环境和启动前状态。本需求只建立基线，不修改业务逻辑、不填入真实密钥、不追求跑通完整产品。

## 2. 状态

| 属性 | 内容 |
|---|---|
| 状态 | 未开始 |
| 所属阶段 | P01-S01 参考项目运行与实验 |
| 必需前置 | 无 |
| 主要交付物 | `progress/p01/reference_baseline.md` |

## 3. 目标

- 确认仓库 URL、默认分支、commit SHA 和 License；
- 确认实际目录、包管理方式、后端运行方式和基础设施依赖；
- 枚举环境变量并按必需、可选、敏感和付费分类；
- 建立后续实验可以对照的干净状态。

## 4. 实现范围

- 将参考仓库放入 `references/p01-backblaze-ai-saas-starter-kit/`；
- 阅读根 README、License、环境变量样例、容器配置、数据库迁移和项目级开发说明；
- 记录前端、后端、数据库、认证、Stripe、对象存储和模型服务的实际版本或配置来源；
- 记录本机所需运行时与当前可用版本；
- 执行不会产生外部写入的基础安装或静态检查可行性判断；
- 保存初始 `git status`、远程地址和 commit SHA。

## 5. 边界

- 不修改参考项目文件；
- 不把真实密钥写入 `.env` 示例、日志或进度文档；
- 不注册付费服务或部署；
- 不根据路线文档替代实际仓库内容；
- 不开始自己的 Java 项目。

## 6. 交付物

`reference_baseline.md` 至少包含：

- 来源与版本；
- License；
- 目录和主要模块；
- 启动组件与命令；
- 环境变量分类表；
- 外部服务与费用/账户要求；
- 当前可运行条件和缺失条件；
- 初始 Git 状态；
- 下一需求需要用户提供或决定的事项。

## 7. 验收标准

- 任意后续 Agent 能定位到完全相同的上游版本；
- 所有 Secret 只记录变量名和用途，不出现真实值；
- 前后端和基础设施启动关系可被复述；
- 付费或外部账户依赖没有被隐式跳过；
- 参考仓库保持无业务改动状态。

## 8. Coding Agent 执行要求

只执行本需求。完成必要读取和安全检查后，报告交付物、命令结果、阻塞和参考仓库 `git status`，然后停止。不得提交、推送或进入 P01-S01-02。
