# P01-S01：参考项目运行与实验

## 1. 目标

在未修改和受控修改两种状态下理解 Backblaze AI SaaS Starter Kit 的真实产品行为，为后续架构拆解提供可追溯证据。

## 2. 子需求

| 子需求 | 目标 | 必需前置 |
|---|---|---|
| P01-S01-01 | 建立仓库、版本和环境基线 | 无 |
| P01-S01-02 | 跑通可以获得条件支持的核心用户流程 | P01-S01-01 |
| P01-S01-03 | 通过注释和小改动验证关键理解 | P01-S01-02 |

## 3. 阶段边界

- 可以修改 `references/p01-backblaze-ai-saas-starter-kit/`；
- 基线运行完成前不修改业务逻辑；
- 不把参考项目技术栈自动确定为正式项目技术栈；
- 不复制源码到 `projects/`；
- 不为了跑通所有可选服务购买资源，付费前先由用户决定；
- 不开始 P01 正式项目实现。

## 4. 阶段交付物

建议在 `progress/p01/` 形成：

```text
reference_baseline.md
upstream_run_report.md
reference_experiments.md
```

文件名可根据实际情况调整，但三类信息必须独立可追溯。

## 5. 阶段完成定义

1. 上游仓库和 commit SHA 已记录；
2. 环境、依赖、外部服务和启动方式已核实；
3. 至少一条可运行用户流程有证据，无法运行部分有明确阻塞；
4. 至少完成两项与学习目标相关的受控实验，或说明不适合实验的原因；
5. 工作区改动、测试结果、Secret 风险和 Git 状态已报告；
6. S02 所需的入口文件、核心模块和疑问清单已经形成。
