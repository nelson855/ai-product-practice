# P02-S01：参考 Workflow 运行与实验

## 1. 目标

基于 DAIR.AI Deep Research Agent 的真实版本，观察 Planner、Search、Writer、Streaming 和部署依赖的实际行为，并通过小改动验证流程控制权。

## 2. 子需求

| 子需求 | 目标 | 前置 |
|---|---|---|
| P02-S01-01 | 建立参考项目和环境基线 | 无 |
| P02-S01-02 | 跑通一条完整或可分段验证的研究 Pipeline | P02-S01-01 |
| P02-S01-03 | 实验阶段边界、控制权和进度表现 | P02-S01-02 |

## 3. 阶段边界

- 可以修改参考项目，但必须先完成未修改基线；
- 不将项目名称中的 Agent 或 Multi-Agent 当成架构事实；
- 不使用模型内部知识替代真实 Search；
- 不开始 Java 正式实现；
- 不购买外部服务或部署资源，除非用户明确同意。

## 4. 建议交付物

```text
progress/p02/reference_baseline.md
progress/p02/upstream_pipeline_report.md
progress/p02/control_experiments.md
```

## 5. 阶段完成定义

- 版本、License、环境和外部服务已记录；
- 至少一个研究任务被完整或分段验证；
- Planner、Search、Writer 的真实输入输出可观察；
- 控制权和进度实验有前后对比；
- 已形成 S02 所需的源码入口与问题清单；
- 修改、测试和 Git 状态已报告。
